Ford Pro og FORDLiive

  • Ford Pro Telematics. Tjenesten er til vognparker med fem eller flere erhvervsbiler med FordPass Connect og viser ydeevne, placering, brug og kørsel i realtid.
  • FORDLiive. Ifølge Fords pressemeddelelse fra 4. maj 2022 aktiverer kunden tjenesten og deler livedata med Ford Transit Erhvervscentre og Ford Pro-specialister. Centret kan gå 60 dage tilbage i kørselshistorikken.
  • Nedetid. Ford anslår, at FORDLiive kan reducere den tid, varebilerne holder stille, med op til 60 %.

Volkswagen ConnectedFleet

  • Data. ConnectedFleet viser tid til næste service, vigtige fejlkoder, motorlamper og batterispænding.
  • Krav. Én bil er nok, og bilen kan være leaset. Den skal være fra efter 2010.
  • Kendetegn. Et klistermærke på indersiden af dørrammen ved førersædet viser, at ConnectedFleet er installeret.
  • Brugere. Flådeadministratoren inviterer brugere og bestemmer deres rettigheder. Chaufførerne kan bruge appen ConnectedFleetCar.
  • Deaktivering. Bilen kan deaktiveres, og aktiveres den igen, er data fra perioden ikke tilgængelige.

Kilde: Volkswagen: ConnectedFleet, set den 4. oktober 2026. Volkswagen samarbejder med ABAX om en udvidet løsning med kort og geofencing på samme dongle.

Volkswagen Fleet Interface Data

Data fra Volkswagen-koncernens biler leveres via en teknisk grænseflade (API) direkte til det flådesystem, virksomheden bruger. Der er datapakker med reparations-, service- og driftsdata.

Mercedes-Benz via Webfleet

Webfleet henter ladetid, rækkevidde, batteristatus og strømforbrug fra Mercedes-Benz' elbiler og el-varebiler gennem programmet OEM.connect. Det kræver kun stelnummeret og ingen ekstra hardware, skrev IT Supply Chain i september 2023.

Opladning fra producenten

Ifølge Fords pressemeddelelse fra maj 2022 dækker Ford Pro Charging opladning på adressen, offentligt og hjemme hos føreren med Ford Connected Wallbox, og den flådeansvarlige kan følge opladningen. Ford giver adgang til BlueOval Charge Network med over 450.000 offentlige ladepunkter.

Dataforordningen

EU's dataforordning gælder fra 12. september 2025 og giver brugere af forbundne produkter, også virksomheder, ret til adgang til de data, produkterne genererer, skriver Europa-Kommissionen.

Persondata

Forbundne biler registrerer lokation, ruter og køreadfærd, som ofte kan knyttes til en person, skriver Datatilsynet. Kunden underskriver en databehandleraftale, når ConnectedFleet aktiveres. Du kan læse reglerne for GPS i firmabiler under GPS-sporing af medarbejdere.

Det skal forhandleren svare på

Så ved I, hvilke data bilen kan levere.

  • Om bilen har indbygget modem, og hvilke tjenester der er aktiveret fra fabrikken.
  • Hvor længe tjenesten er inkluderet, og hvad den koster bagefter.
  • Hvilke data der leveres: position, km, service, batteri og opladning.
  • Om data kan hentes via API til jeres flådesystem.
  • Hvem der er dataansvarlig, og om der skal underskrives en databehandleraftale.

Ofte stillede spørgsmål

Kan man få flådedata fra bilen uden at montere en GPS-tracker?

Ja, for flere mærker. Ford Pro Telematics bruger FordPass Connect i vognparker med mindst fem Ford-erhvervsbiler, Volkswagens Fleet Interface Data leverer data via API, og Webfleet henter data fra Mercedes-Benz el-varebiler ud fra stelnummeret.

Hvad koster Volkswagens ConnectedFleet?

Den er gratis, når bilerne serviceres på et autoriseret værksted i VW-koncernen, og den virker på alle bilmærker fra efter 2010.

Hvad er FORDLiive?

Det er en tjeneste fra Ford, hvor kunden deler livedata fra varebilen med Ford Transit Erhvervscentre, ifølge Fords pressemeddelelse fra maj 2022. Centret kan se 60 dages kørselshistorik og bestille reservedele hjem på forhånd.

Kan flådesystemet vise batteriniveau fra producentens data?

Ja. Webfleet henter batteristatus, rækkevidde og ladetid fra Mercedes-Benz el-varebiler, og Volkswagens Fleet Interface Data leverer resterende rækkevidde.

Har virksomheden ret til data fra sine biler?

Ja. Fra 12. september 2025 giver EU's dataforordning brugerne, også virksomheder, ret til adgang til data fra forbundne produkter som biler.
